Dictator

Minimal, local-only dictation for macOS. Press a shortcut, talk, and the text is typed into whatever field has focus. Transcription runs on-device with Whisper Large v3 Turbo (WhisperKit Core ML), bundled inside the app.

Download the latest release

Requirements

  • macOS 15 or later
  • A Mac with Apple silicon

First launch: “Open Anyway”

Dictator isn’t signed with an Apple Developer ID yet, so macOS blocks it the first time. Try to open it once, then go to System Settings → Privacy & Security and click Open Anyway. Then grant Microphone, Input Monitoring and Accessibility when asked.
